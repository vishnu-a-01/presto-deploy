# Accessibility

## Operable (Keyboard + focus)

- Buttons share a **visible focus ring** (`ring-2 ring-white`) through `.btn:focus` and `.btn:focus-visible`, supporting keyboard navigation.
- Disabled states are visually communicated for slide navigation controls.

## Perceivable (Text alternatives + clarity)

- Images and embedded content include accessible text where applicable:
	- Presentation thumbnails include `alt` text.
	- Image elements use user-supplied alt text (with fallback).
	- Embedded videos include an iframe `title`.

## Understandable (Clear labeling)

- Inputs use descriptive placeholders and nearby labels in element modals.
- **`aria-label` coverage on buttons** ensures screen readers can announce purpose even when the visible label is ambiguous.
